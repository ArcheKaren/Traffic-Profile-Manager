# Источник runtime

Git-репозиторий не хранит сторонние runtime-бинарники.

Скачайте официальный
[`zapret-win-bundle`](https://github.com/bol-van/zapret-win-bundle) и распакуйте
его так, чтобы каждый файл находился по точному относительному пути, указанному в
`SOURCE.json`. Обычный аудит и релизная сборка проверяют именно эти пути, размеры
и SHA-256. Рекурсивный поиск используется только при локальной диагностике с
`-SkipRuntimeProvenanceCheck` и не подходит для публикации.

Для релиза нужны:

- `winws2.exe`;
- `WinDivert.dll`;
- `WinDivert64.sys`;
- `cygwin1.dll`;
- `zapret-lib.lua`;
- `zapret-antidpi.lua`.

Источник, дата скачивания и SHA-256 upstream-архива записаны в `SOURCE.json`.
Там же зафиксированы точные относительные пути, размеры и SHA-256 шести
компонентов, которые разрешено помещать в релиз. Сборка останавливается при
любом несовпадении.

После обновления upstream заново вычислите хеш архива и каждого выбранного
файла, обновите `SOURCE.json` и выполните полный аудит. Флаг сборщика
`-SkipRuntimeProvenanceCheck` предназначен только для локальной диагностики и
не должен использоваться при публикации.

Чтобы указать runtime вне этого каталога:

```powershell
.\zapretctl.cmd runtime path C:\tools\zapret-winws\winws2.exe
```

Условия сторонних проектов перечислены в
[`THIRD-PARTY-LICENSES.txt`](../THIRD-PARTY-LICENSES.txt).
