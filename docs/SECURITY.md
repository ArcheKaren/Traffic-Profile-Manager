# Политика безопасности

## Поддерживаемая версия

Исправления безопасности применяются к последнему опубликованному релизу.

## Сообщение об уязвимости

Не создавайте публичную задачу, если проблема может:

- выполнять непредусмотренные команды от администратора или SYSTEM;
- изменять файлы вне управляемых путей программы;
- оставлять неуправляемую службу WinDivert, задачу или runtime-процесс;
- повреждать Windows `hosts`;
- раскрывать локальные идентификаторы или сетевые данные.

Используйте приватные security advisory GitHub владельца репозитория. Укажите
версию, порядок воспроизведения, ожидаемый ущерб и возможное исправление.

## Границы доверия

- JSON-профиль является доверенной исполняемой конфигурацией и обрабатывается с
  правами администратора.
- Сторонние runtime-бинарники не собираются этим репозиторием.
- Служба и SYSTEM-задача выполняются из защищённого снимка в `%ProgramData%`;
  обычные пользователи не должны иметь право записи в этот каталог.
- Runtime защищённого снимка сверяется с размерами и SHA-256 из
  `runtime\SOURCE.json`.
- Пользователь релиза должен сверять опубликованную контрольную сумму.
- При обновлении временных сопоставлений выбранные имена передаются Cloudflare
  DNS или Google Public DNS.
- Приложение не содержит аналитики или телеметрии.
