# Проверка стратегий и доменов — ноябрь 2026

Проверено 12 ноября 2026 года. Это обновление данных каталога; версия менеджера остаётся 1.2.1.

## Стратегии и runtime

Все 14 комплектных JSON-профилей и их BAT-файлы сохранены. Используемые fake,
multisplit/multidisorder, seqovl, autottl, TCP timestamps и QUIC-приёмы остаются
поддерживаемыми. Дата создания профиля сама по себе не означает, что его нужно заменить.

**1. Base (`strategy-wa-pc-pos1`)** и **9. Current defaults (`strategy-current-default`)**
оставлены отдельными вариантами. У них разные сочетания приёмов; без измерений на
конкретном подключении оснований объединять их в один «лучший» профиль нет.

Официальный пример `preset2_example.cmd` из zapret-win-bundle от 9 ноября совпадает
с примером, на котором основан Current defaults. Остальные профили остаются
альтернативами для сравнения на своём провайдере. Для приёма `tcp_ts` требуется наличие TCP timestamp option в соединении;
обновление не меняет сетевые настройки системы.

Штатный runtime 1.0.3 сохранён: новым доменам не нужны новые параметры движка.
Аргументы и необходимые файлы всех профилей дополнительно проверены на официальном
zapret2 1.0.7 от 5 ноября в изолированной копии с его собственными DLL и Lua-файлами.
Пять бинарных образцов в `assets` совпадают с актуальными образцами upstream
и также не заменены.

Источники каталога закреплены в `lists/catalog.json`:

- [Flowseal: список целей, commit 2401b7a от 4 ноября](https://github.com/Flowseal/zapret-discord-youtube/blob/2401b7a13837139b0265632464ba563dddbf80d8/lists/list-general.txt);

- [Signal: документация владельца](https://support.signal.org/hc/en-us/articles/360007320291-Firewall-and-Internet-settings): домены ссылок и общего доступа.

Это подборка целей и зависимостей сервисов для использования с профилями, а не полный
реестр блокировок. Добавление домена не подтверждает его блокировку у каждого
провайдера и не устраняет ограничения по IP, геолокации или учётной записи.
Доменные списки сами по себе не гарантируют работу голосового UDP-трафика.

Пользовательские `user-*`, собственные пакеты и выбор включённых пакетов сохраняются.
JSON и TXT по-прежнему можно редактировать обычным текстовым редактором.

## Проверки

Проверены структура и уникальность каталога, схемы профилей, генерация аргументов
и настоящий `winws2 --dry-run` для каждого из 14 профилей на runtime 1.0.3 и 1.0.7.
Контрольные суммы исходных профилей и пяти assets сопоставлены до и после работы.
Модульные тесты: 125/125 в Windows PowerShell 5.1 и 125/125 в PowerShell 7;
smoke и проверка конструктора с `--dry-run` проходят. Переносимая сборка проходит
штатные проверки проекта; ZIP проверяется по всем
включённым файлам при сборке. Пользовательские данные в локальных папках релиза сохраняются отдельно.

`--dry-run` не инициализирует Lua и не перехватывает трафик. Подтверждение работы
Lua-стратегии и её эффективности требует
обычного сравнения профилей на вашем подключении после обновления.
