# Проверка сборки и права администратора

[Основное руководство](../README.md) · [English quick guide](README.en.md#verify)

## Зачем программе нужны права администратора

- `winws2` использует WinDivert для перехвата и изменения сетевых пакетов.
  Работа драйвера требует повышения прав.
- Модуль временных сопоставлений изменяет только блок между маркерами
  `# TrafficProfileManager Mapping BEGIN/END` в системном файле `hosts`.
  Строки вне этого блока сохраняются; блок очищается при завершении профиля.
- Установка службы Windows и связанной задачи требует прав администратора.
  Эти действия выполняются по выбору пользователя.

`Manager.bat` повышает права при открытии всего менеджера. Для просмотра и
проверок можно использовать CLI без повышения, например:

```powershell
.\zapretctl.ps1 profile list
.\zapretctl.ps1 version --json
.\zapretctl.ps1 check strategy-wa-pc-pos1
```

Последняя команда проверяет параметры через `winws2 --dry-run`.
Описание профиля — доверенная конфигурация, которая при реальном запуске
обрабатывается с правами администратора. Проверяйте источник чужих профилей.

## Как проверить скачанный ZIP

1. Откройте [официальные релизы](https://github.com/ArcheKaren/Traffic-Profile-Manager/releases/latest).
2. Скачайте `TrafficProfileManager.zip` и `SHA256SUMS.txt` из одного релиза.
3. Откройте PowerShell в папке с обоими файлами и выполните:

```powershell
$actual = (Get-FileHash -LiteralPath .\TrafficProfileManager.zip -Algorithm SHA256).Hash
$checksums = Get-Content -LiteralPath .\SHA256SUMS.txt -Raw
$expected = [regex]::Match($checksums, '(?m)^([A-Fa-f0-9]{64})\s+\*?TrafficProfileManager\.zip\s*$')
if (-not $expected.Success -or $actual -ine $expected.Groups[1].Value) {
    throw 'SHA-256 не совпадает. Не запускайте этот архив.'
}
"SHA-256 совпадает: $actual"
```

Хеш должен совпасть полностью. При несовпадении скачайте оба файла заново
с официальной страницы; не используйте повреждённый или подменённый архив.

SHA-256 подтверждает, что ZIP совпадает с опубликованным файлом. Он не является
проверкой исходного кода, цифровой подписью или гарантией безопасности.

## Что можно проверить в исходниках и CI

- [Исходный код менеджера и CLI](https://github.com/ArcheKaren/Traffic-Profile-Manager).
- [Проверки проекта](https://github.com/ArcheKaren/Traffic-Profile-Manager/actions/workflows/validate.yml):
  анализ PowerShell, unit-тесты, smoke-проверка, завершение видимого профиля,
  переносимость путей, жизненный цикл службы и сборка ZIP.
- [Публикация релизов](https://github.com/ArcheKaren/Traffic-Profile-Manager/actions/workflows/release.yml):
  проверка тега, восстановление зафиксированного runtime, проверка архива
  и публикация ZIP с контрольной суммой.
- [Инструкция сборки](CONTRIBUTING.md#проверки-и-сборка).
- [runtime/SOURCE.json](../runtime/SOURCE.json): происхождение, размеры и SHA-256
  выбранных сторонних компонентов. Бинарники upstream не собираются этим
  репозиторием; сборщик проверяет их по зафиксированным сведениям.

В распакованной сборке команда `zapretctl version --json` показывает версию,
коммит исходников и `localChanges` на момент сборки. Эти сведения хранятся
в `metadata/BUILD-INFO.json`. Поле `contentSha256` описывает содержимое сборки
при её создании и отличается от SHA-256 всего ZIP.

## Почему антивирус может предупреждать о WinDivert

Перехват и изменение сетевого трафика могут классифицироваться как PUA или
RiskTool. [Upstream также описывает предупреждения антивирусов](https://github.com/bol-van/zapret-win-bundle/blob/master/readme.md#антивирусы).
Сам факт использования WinDivert не доказывает, что любое предупреждение ложно.
Проверьте источник, хеши и сведения об обнаружении перед запуском. Не отключайте
защиту всей системы ради запуска программы.

## Какие данные покидают компьютер

Собственной аналитики и телеметрии в приложении нет. Журналы и отчёты
сохраняются локально. Сетевые обращения нужны для выбранных пользователем
проверок адресов, разрешения настроенных сопоставлений через Cloudflare DNS
или Google Public DNS и явной проверки/загрузки обновлений GitHub.
Перед публикацией диагностических отчётов удаляйте личные адреса и пути.

Уязвимости сообщайте по [политике безопасности](SECURITY.md).
Условия сторонних компонентов перечислены в [THIRD-PARTY-LICENSES.txt](THIRD-PARTY-LICENSES.txt).
