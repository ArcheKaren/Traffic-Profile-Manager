# Локальная диагностика приложений

Диагностика помогает отделить проблему DNS, подключения TCP/443 и состава
целевых адресов. Она не записывает содержимое пакетов и не отправляет отчёты.

Запуск через **Manager → Application diagnostics** предлагает готовую группу.
Из консоли можно указать её ID:

```text
zapretctl diagnose meta-quest
zapretctl diagnose instagram
zapretctl diagnose github
```

В `test-results` создаются TXT и JSON с одинаковой временной меткой. Отчёт
содержит:

- версию программы, ревизию каталога и активный профиль;
- включённые пакеты доменов;
- версию Windows и PowerShell, статус администратора и DNS-серверы;
- адреса, время DNS и результат подключения TCP/443 для выбранной группы;
- уникальные имена, найденные в последних 400 строках локального журнала
  `logs\winws2.log`.

Каталог групп находится в `config\diagnostic-targets.json`. Для автономной
проверки формата отчёта без сетевых запросов используется ключ `-NoNetwork` у
`tools\application-diagnostics.ps1`.

Перед передачей отчёта другому человеку просмотрите поле
`observedHostNames`: оно может отражать имена, с которыми недавно работал
локальный runtime. Удаление файлов из `test-results` не влияет на программу.
