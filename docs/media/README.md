# Демонстрация менеджера

`manager-demo.gif` — 25-секундная анимация настоящего консольного вывода,
перерисованного для читаемости в README. Это четыре сокращённые сцены,
а не непрерывная запись рабочего стола:

1. Главное меню с группами пунктов.
2. Список готовых профилей; выбор отменяется без запуска профиля.
3. Успешная реальная проверка Base через `winws2 --dry-run`.
4. Просмотр сохранённого сравнения от 28 июля 2026 года.

Рейтинг не выдуман и не обновлён до текущей даты. Обезличенный исходный пример
[profile-comparison-20260728-125142.csv](profile-comparison-20260728-125142.csv)
содержит 136 результатов: 8 профилей и 17 проверок для каждого. Из исходного
локального отчёта оставлены только `ProfileId`, `Profile` и `Success`.
Адреса целей, детали ошибок, сетевые идентификаторы и локальные пути удалены.
Старое название `Verified baseline` сохранено как часть исторического отчёта.

Результаты относятся к конкретному подключению и списку целей в момент того
запуска. Они не означают, что такой же рейтинг получится у другого пользователя.

## Повторное создание

В исходном репозитории с подготовленным runtime выполните из корня проекта:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\tools\build-demo.ps1
```

Нужен Windows PowerShell 5.1. Используются штатные .NET-компоненты Windows;
дополнительные редакторы, Python и сервисы генерации изображений не требуются.
Скрипт создаёт изолированную копию во временной папке `tests/.tmp-demo-*`,
выбирает английский язык только в этой копии, захватывает вывод настоящего
менеджера и CLI и удаляет временную копию после завершения. Для фиксации границ
экранов в копии заменяется только функция очистки терминала. Рабочий профиль
не запускается, служба не устанавливается, системный `hosts` не изменяется.

В переносимой сборке остаются сама анимация, это пояснение и обезличенный CSV.
Генератор предназначен для разработчиков и находится только в исходниках.
