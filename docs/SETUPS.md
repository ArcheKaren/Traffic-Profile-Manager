# Именованные наборы, конструктор и применение настроек

Менеджер и BAT/CLI используют одни и те же обычные JSON/TXT-файлы. База данных,
графический интерфейс и обязательный фоновый мониторинг не нужны.

## Именованные наборы

Откройте **Manager → Named setups and application** (пункт 20). При первом входе
текущие настройки сохраняются как `main` («Основной»). Создание набора сохраняет
текущие настройки; переключение сначала показывает заменяемые файлы.

Набор содержит:

- ID выбранного профиля стратегии;
- включённые пакеты доменов и игровые фильтры;
- универсальный игровой транспорт, его режим и порты;
- параметры `autoHostlist`, `debug`, `allowAllWithoutTargets`;
- четыре собственных TXT-списка пользовательских целей и исключений.

Язык интерфейса, путь к runtime, журналы, PID и кэши в набор не входят.
Определения стратегий, пакетов и фильтров остаются отдельными файлами:
набор ссылается на них по ID, а не создаёт скрытые копии. Изменение определения
по тому же ID влияет на все наборы, которые его используют.

```text
state/setups/home/
  setup.json
  user-domains.txt
  user-domains-exclude.txt
  user-ips.txt
  user-ips-exclude.txt
```

В `setup.json` находятся поля `schemaVersion`, `id`, `displayName`, `profile`,
`domainPacks`, `gameFilters`, `universalTransport` и `options`. Формат можно
посмотреть командой `setup show`; комментарии размещайте в TXT строками с `#`.
Не меняйте `id` отдельно от имени каталога. Данные наборов не попадают в Git
и чистую сборку, но включаются в резервные копии пользователя.

```bat
zapretctl.cmd setup list
zapretctl.cmd setup create home
zapretctl.cmd setup show home
zapretctl.cmd setup preview home
zapretctl.cmd setup use home
zapretctl.cmd setup save home
tools\run-setup.bat home
```

`create` сохраняет новый набор, `save` явно заменяет существующий текущими
настройками, `use` применяет сохранённый набор к рабочим файлам. Ручные правки
в рабочей папке не записываются обратно в набор автоматически. Перед
переключением сохраните нужные изменения. Настройки, списки и выбранный набор
меняются одной файловой транзакцией; результат содержит ID для отката.

Переключение требует остановленного профиля или службы. Служба может оставаться
установленной, но её защищённая копия применяется отдельным действием.
`run-setup.bat` запрашивает права администратора, применяет набор и запускает его
в видимом окне. При установленной службе видимый запуск отклоняется **до**
переключения. Существующие 14 BAT-профилей продолжают работать как раньше.

Для собственного BAT используйте обычный вызов с постоянным ID:

```bat
@echo off
call "C:\Path\TrafficProfileManager\tools\run-setup.bat" home
```

## Конструктор профилей

**Manager → Create a custom profile → Build a profile step by step** позволяет
выбрать основу и отдельно взять действия HTTP, TLS и QUIC из других корректных
профилей. Перехват портов, условия отбора и специальные правила Discord/WhatsApp
сохраняются из основы. Конструктор не пытается объединять произвольные правила
или угадывать совместимость всех параметров zapret2.

Перед сохранением показывается итоговый JSON. После `CREATE` выполняются
проверка схемы и настоящий `winws2 --dry-run` в изолированной папке. Профиль
публикуется только при успешной проверке; это проверка параметров, а не обещание
работы на конкретном подключении. При конфликте blob-имён сборка отклоняется.

Результат — обычный `config/profiles/<id>.json`, доступный старым запускателям,
редактору и сравнению. Существующий ID не перезаписывается, поэтому ручные правки
не теряются. Цели и исключения задаются привычными списками или набором.

Для повторяемой сборки можно создать текстовый рецепт:

```json
{
  "schemaVersion": 1,
  "id": "my-network",
  "displayName": "My network",
  "baseProfile": "strategy-wa-pc-pos1",
  "httpProfile": "",
  "tlsProfile": "strategy-variant-split1",
  "quicProfile": "strategy-variant-quic"
}
```

Пустое поле стратегии сохраняет вариант из основы.

```bat
zapretctl.cmd build-profile preview recipe.json
zapretctl.cmd build-profile create recipe.json
```

Рецепт созданного профиля сохраняется в `state/profile-recipes/<id>.json` и
включается в резервные копии. Для нового варианта укажите новый ID; обычный
ручной редактор JSON остаётся доступен.

## Контроль применения

**Show status** и раздел наборов показывают состояние `applied`, `pending`,
`stopped` или `unknown` и список отличающихся файлов/параметров. Проверяются
профиль запуска, основные параметры, списки, выбранные игровые фильтры,
используемые blob-файлы и определения сопоставлений. Смена языка или изменение
неиспользуемой стратегии не требуют перезапуска текущего профиля.

```bat
zapretctl.cmd configuration status
zapretctl.cmd configuration status -Json
zapretctl.cmd configuration apply
```

Снимок видимого/фонового запуска связан с PID, временем создания и путём
исполняемого файла. Старый снимок не подтверждает работу нового процесса.
Если снимка нет, выводится `unknown`, а не предполагается, что настройки
применены. При прямом запуске BAT учитывается явно выбранный профиль.
Профиль из конфигурации и профиль запуска показываются отдельно; применение
к службе использует профиль из текущей конфигурации. При работающем профиле о различии выводится предупреждение.

Для видимого режима примените изменения привычным закрытием окна и новым
запуском. `configuration apply` предназначен для **установленной** службы:
проверяет кандидата установленным runtime, сохраняет прежние файлы и команду SCM,
обновляет защищённую копию и перезапускает ранее работавшую службу. Остановленная
служба остаётся остановленной. Тип запуска и наличие задачи не меняются.
При ошибке выполняется восстановление прежней конфигурации; неполный откат
сообщается явно. Действие не обновляет бинарники или код программы.

## Улучшенное сравнение стратегий

Прежний пункт **Test and compare profiles** предлагает быстрый и полный режимы.
Быстрый делает один проход и дополнительно проверяет лидеров, полный — несколько
проходов каждого профиля. Настройки редактируются в `config/benchmark.json`,
адреса — в `tests/targets.txt`. Доступен и прямой запуск PowerShell:

```powershell
.\tools\profile-benchmark.ps1 -Mode quick -NonInteractive
.\tools\profile-benchmark.ps1 -Mode full -Rounds 3 -NonInteractive
.\tools\profile-benchmark.ps1 -Profiles strategy-wa-pc-pos1,strategy-variant-quic -SkipBaseline
```

Перед запуском профилей выполняется контрольный замер без них, с текущими DNS
и `hosts` системы. Существующие сеансы не останавливаются автоматически.
Отмена в меню не устанавливает сопоставления и не запускает фоновые компоненты.

В CSV сохраняются `Round` и `FailureKind`, в TXT — рейтинг и сводка ошибок DNS,
TCP, TLS, таймаутов и HTTP. `Success` по-прежнему означает HTTP-доступность
(2xx–5xx), `Healthy` — ответ 2xx–4xx. Стабильная цель ответила во всех повторных
проверках; один успешный запрос стабильность не подтверждает. Быстрый режим
повторяет только лидеров — это явно указано в отчёте. Контрольный замер не
участвует в выборе запускаемого профиля. Если улучшения не измерено или все
цели недоступны, программа сообщает об этом вместо обещания рабочей стратегии.

HTTP-проверка не измеряет игровой пинг и не подтверждает работу голосового UDP.
Сохранённые сравнения прежнего формата по-прежнему доступны.
